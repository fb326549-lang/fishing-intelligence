# 台灣岸釣努力量與魚種權重驗證方法

## 目的

本文件只處理漁獵雷達三項指標及FCI權重所需的釣獲努力量驗證，不新增釣魚紀錄功能，也不把其他區域的CPUE直接套用到台灣東部。

## 1. 可用的官方資料與限制

### iOcean垂釣回報（海保署）

政府資料開放平台資料集157622為免費開放資料。公開資料字典列出：
- Fishing_Time（垂釣時間）
- People_Count（同行人數）
- WGS84X / WGS84Y（位置）
- Species_Name / Name_Code（魚種與學名代碼）
- Fishing_Count（尾數）
- Fishing_Length（體長）
- Type_Name（垂釣類型）

官方2024年《海洋漫波》第20期說明：垂釣時數及現場垂釣人數屬非必填欄位；若正確填寫，可用於估算垂釣努力量。這代表iOcean並非完全沒有努力量概念，但努力量欄位可能缺漏，且目前公開資料字典未明列垂釣時數欄位。正式使用前必須先檢查實際CSV/JSON原始欄位及非空比例，不得只憑資料集摘要推定已具備完整努力量。

官方2025年「垂釣回報執行與分析暨釣點漁獲食用安全調查計畫」資料集說明已累積約10,000筆回報，並建立科學調查與抽樣方法進行釣獲量推估。該成果報告仍須取得全文，確認其抽樣框、回報校正、努力量欄位及估計公式後，才能移植其方法。

### 2. 官方現場抽樣研究可提供的努力量方法

**106年度墾丁國家公園海域垂釣魚類資源量監測調查（2）**
- 2017年調查10個公告測站及12個非公告垂釣區。
- 每季安排約兩週調查，每日分上午、下午兩梯次，每梯次每釣區約3–4小時。
- 共記錄5,080尾；報告明確採用「尾數／小時／人」或「公斤／小時／人」作為努力量單位。
- 2017年記錄到褐臭肚魚（Siganus fuscescens）200尾；另有舵魚屬（Kyphosus spp.）202尾。
- 舵魚僅鑑定到屬，不能當作南方舵魚K. bigibbus的物種級釣獲證據；墾丁資料亦不是台灣東部資料。
- 報告中的CPUE、努力量標準化與分季抽樣可作方法參考，但不可把該區域魚種數量或CPUE直接移植為東部模型權重。

**台灣北部港區垂釣行為研究（2013–2014）**
- 15處港區、73次抽樣調查、408份問卷。
- 整體平均漁獲率約1.37±2.99尾／小時／人，估計總努力量約522,515小時。
- 2,857尾樣本中，臭肚類約占65%（1,843尾）。
- 這是北部港區、特定抽樣與受訪者樣本，不能當作台灣東部岩岸CPUE；但可證明以人時標準化並結合現場抽樣估算休閒釣獲量是可行方法。

## 3. 本系統採用的標準化定義

若原始回報有可驗證的有效垂釣時數與人數：

\[
E_i=H_i\times P_i
\]

其中：
- \(H_i\)：第i筆／次有效垂釣時數（小時）
- \(P_i\)：實際參與垂釣人數
- \(E_i\)：人時努力量（angler-hours）

物種級尾數CPUE：

\[
CPUE_{s,r,t}=\frac{\sum CatchCount_{s,r,t}}{\sum E_{r,t}}
\]

物種級重量CPUE（只有體重資料可靠時）：

\[
CPUE^{kg}_{s,r,t}=\frac{\sum CatchWeight_{s,r,t}}{\sum E_{r,t}}
\]

計算前必須：
1. 魚種學名代碼通過鑑定；「白毛／舵魚屬」未鑑種資料不得併入南方舵魚。
2. 垂釣位置、時間、釣法、有效時數及人數可追溯。
3. 排除重複回報、時間不合理、位置不合理及無法辨識魚種資料。
4. 區分零漁獲努力量與未回報；沒有魚獲回報不能自動視為零漁獲。
5. 按海域、月份、時段、釣法及棲地分層；不得將不同區域或不同釣法直接合併。
6. 以獨立日期／釣點留出驗證，避免同一釣友或同一趟釣遊同時進入訓練與驗證資料。

## 4. 東部魚情模型的使用門檻

- **可作背景：** 官方開放回報的正向魚種、時間及位置分布；外地CPUE研究的抽樣設計與計算方法。
- **可作校準：** 台灣東部、物種級鑑定、有效人時努力量完整、且包含零漁獲／未中魚時段的資料。
- **不可作校準：** 只有正向魚獲照片或尾數、沒有努力量；把Fishing_Time日期欄位誤當垂釣時數；把屬級Kyphosus spp.當成K. bigibbus；把墾丁或北部港區CPUE當作台東／花蓮CPUE。

目前下一個必要資料工作是取得iOcean原始CSV/JSON，核對是否含垂釣時數欄位及其完整率，並取得海保署2025年調查計畫成果報告全文。完成這兩項稽核後，才決定可用資料能否支持南方舵魚、臭肚、黑鯛等物種的東部CPUE與FCI權重校準。
