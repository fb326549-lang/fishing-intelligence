# 臭肚（Siganus fuscescens）魚種專屬反應模型研究規格

## 身分及適用範圍

模型對象為臭肚 *Siganus fuscescens*（候選 c003）。以學名及可核對的物種紀錄為準；俗名及近似種紀錄不可自動併入。此規格整理目前登錄的物種證據，並定義可驗證的模型結構，不代表已具備台灣東部即時計分資格。

## 三項指標的候選結構

### 覓食條件

候選輸入包括逐時海溫、當地日出日落相位、藻類種類與生物量／可利用量，以及其他經胃含物或觀察確認的天然食物。溫度反應須按食物種類分層；不可將不同藻種試驗合併成單一溫度曲線。形式上可記為 `F_c003(t) = f(SST, prey_type, prey_availability, light_phase, season)`。L058提供台東都蘭灣歷史藻類群聚背景，但沒有確認主要藻種對臭肚的可食性或同步魚類反應，且年代僅2001–2003、單一礁區，不能當作目前六區逐時餌源代理。雷達仍缺東部逐時天然餌源資料及野外校準函數，故正式覓食分數不可由此解鎖。

### 環境適合度

候選輸入為海溫、流速／方向、潮汐階段及變化、浪高／週期、棲地類型與餌源棲地。所有反應方向及函數形狀須由已鑑定臭肚的東部野外資料估計；不得把水槽研究門檻或其他魚種規則移用。現階段缺少可核准的物種反應規則，指標保持 unavailable。

### 魚類活動力

候選輸入為日出日落相位、季節、海溫、潮汐變化及海流／浪況。L050 僅支持「月份可能調節日夜活動」作為研究假說，不提供方向或幅度參數。要計算需有東部野外標記追蹤、定時潛水／影像或其他可重複的活動量測及無活動對照。

## 資料品質、缺值與驗證

- 日本水槽、遙測與藻場研究維持 context-only；北台灣自然史亦不得冒充東部實測。
- 任一必要食物、環境或活動輸入缺失時，對應指標回報 unavailable 與缺值原因；不得補零或由海溫代替餌源。
- 只可在同一物種、明確方法與地理範圍內估計參數；需保留樣本、時間、地點、觀測方法及來源識別碼。
- 獨立海域／日期留出驗證，並以有努力量和無漁獲／無活動對照資料檢查校準；漁獲結果只用作外部效度，不將活動指數稱為中魚機率。
- `indicator_scoring_rules_template.csv` 及 `species_indicator_weights_template.csv` 維持未核准，不增加猜測門檻或權重。

## 啟用前必要資料

1. 台灣東部臭肚物種鑑定、座標精度、時間精度及季節分層的野外活動／攝食觀測。
2. 同地同時的天然藻類種類、覆蓋或生物量及其他餌源資料。
3. 同步海溫、海流、潮汐、浪況及棲地資料，包含有／無魚或高／低活動對照。
4. 若驗證釣況，須有作釣時數／人時、漁法、釣點、目標魚與零漁獲紀錄。

在資料到位並通過獨立驗證前，本文件是物種專屬研究與資料契約；不產生活動時段推薦、FCI 或中魚機率。
