# 黑鯛（Acanthopagrus schlegelii）魚種專屬反應模型研究規格

## 身分及適用範圍

模型對象為黑鯛 *Acanthopagrus schlegelii*（候選 c004）。俗名資料須以學名／可靠鑑定核對，避免與其他棘鯛混淆。本規格將既有文獻拆成可支持的生態假說及不可移植的漁具、地區限制；目前沒有台灣東部逐時岸釣反應參數。

## 三項指標的候選結構

### 覓食條件

候選輸入包括經當地食性資料確認的餌源類群與可利用量、海溫／季節、棲地、潮汐階段及水流變化。潛在函數為 `F_c004(t) = f(prey_availability, SST, season, habitat, tide/current, diel_phase)`。西部漁業空間模型及異地食性資料只能用來界定研究假說；目前沒有東部即時餌源量或東部釣餌攝食反應，故不計分。

### 環境適合度

候選環境量包括海溫、一般海流與潮流（分開）、潮汐、浪高／週期及棲地。L012–L013 所述西部模型特徵僅保留為來源中的觀測，不轉為規則或初始權重。需要東部已鑑定成魚、同時環境測量及對照地點／時段，才能估計環境響應；不可將遙測海流當近岸潮流。

### 魚類活動力

候選輸入包括季節、日夜相位、繁殖期背景、海溫、潮汐與流浪變化。西部刺網季節漁獲只作地區性漁業觀察，不作逐時活動標籤。需以東部重複野外觀測或追蹤資料直接量測活動，並將繁殖、覓食及一般移動行為分開標記。

## 資料品質、缺值與驗證

- L012–L014 全部維持 `context_only_western_taiwan_fishery_model`；其範圍、漁法與變數定義須隨引用一併保存。
- 異地胃含物、幼生調查及漁業年產資料不得轉換成東部逐時分數。
- 必要輸入缺失時輸出 unavailable 及缺值欄位；不得以平均環境值或其他物種參數填補。
- 以東部獨立海域／日期留出資料驗證反應方向、校準及跨季節穩健性；若使用釣獲作驗證，必須取得人時／船時、漁具、作業位置及零漁獲紀錄。
- 釣獲驗證的目標是 catch rate/CPUE 校準，不把生態 FCI 解讀為中魚機率。
- 目前無核准的規則或權重，維持兩份 scoring/weight templates 空白。

## 啟用前必要資料

1. 台灣東部可確認物種的成魚活動或棲地使用，並涵蓋季節、日夜與不同海況。
2. 同步、近岸尺度且方法一致的 SST、流速／方向、潮汐、浪況與棲地資料。
3. 有地點與季節標記的當地食性和餌源可利用性觀測。
4. 若要聲稱可預測釣獲，需有努力量、漁具、目標物種及零漁獲紀錄，並以獨立時段／海域驗證。

本規格建立黑鯛獨立研究問題及計算接口；沒有資料支持的參數保持未知，不輸出完整 FCI、最佳時段或中魚機率。
