# 瓜子鱲（Girella punctata）魚種專屬反應模型研究規格

## 身分及適用範圍

模型對象為瓜子鱲 *Girella punctata*（候選 c001）。「黑毛」及其他俗名不構成物種鑑定；個體級輸入在確認學名前不得套用本模型。這一身分閘門特別重要，東部的單筆標本／釣獲只能證明曾出現，不解除其他未鑑定個體的限制。

## 三項指標的候選結構

### 覓食條件

候選輸入為當地藻類及無脊椎動物可利用量、季節、海溫、日照相位及礁區棲地。L011 的北部胃含物季節變化可幫助設計餌源採樣類別，但不能設定東部變數權重。候選形式 `F_c001(t) = f(prey_availability, prey_type, SST, season, light_phase, habitat)`；缺乏東部同步餌源與攝食觀測時保持 unavailable。

### 環境適合度

候選輸入包括物種確認後的棲地類型、海溫、浪高／週期、海流／潮流、潮汐及季節。L015 的日行性與岩礁描述只可用於預先定義分層，不可當分數。海域對照需同時含有適用與不適用／未偵測條件，否則無法辨別偏好與單純出現。

### 魚類活動力

候選輸入包括當地日出日落相位、季節、繁殖背景、溫度、潮汐變化及浪流。AE001/SE001 是北部單點季節群聚，不能解成東部活動預測；AE002 是定性日行性概述。需有東部物種確認、時間精確的活動或偵測資料及同設計的未偵測時段。

## 資料品質、缺值與驗證

- 未完成物種級鑑定時，所有三項指標均回報 ineligible_taxon，不得回退到「黑毛」平均值。
- 北台灣歷史野外資料與養殖／圈養數值保持 context-only；來源、生命階段及採樣方法不可丟失。
- 缺少餌源、棲地分類或環境量時，對應指標標示 unavailable 並指出缺失欄位；不補零。
- 參數估計和驗證需按海域及年份分組留出，並分開成魚／幼魚；不可用同一批觀測同時擬合及宣稱驗證。
- 釣獲驗證須另有努力量及零漁獲資料。FCI 是生態條件指標，不能稱為中魚機率。
- 暫無核准規則與物種權重，不建立東部精確溫度或浪流門檻。

## 啟用前必要資料

1. 瓜子鱲個體級形態／影像鑑定資料與可追溯信心等級。
2. 台灣東部成魚、幼魚分開的季節與逐時活動／覓食觀測。
3. 同步礁區棲地、可利用餌源、SST、浪流與潮汐觀測，含未偵測對照。
4. 若輸出釣況驗證，需有釣點、逐時努力量、漁法及零漁獲紀錄。

此規格讓瓜子鱲具有獨立的生態反應問題、證據界線與驗證設計。資料未達標前，模型不得產生東部最佳覓食／活動時段或正式指數。
